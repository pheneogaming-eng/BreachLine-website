# Moja spletna stran – Breachline

Preprosta spletna stran o igri **Breachline**, taktični prvoosebni strelski igri, ki se igra v brskalniku.

Stran vsebuje:
- uvodni opis igre,
- razdelek o mapah,
- sliko iz igre,
- oblikovanje s CSS.

Projekt je nastal pri vaji za utrjevanje ukazov Git (lokalni in oddaljeni repozitorij).
